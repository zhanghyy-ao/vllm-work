# Version Roadmap

## v0.1.0 当前版本

- 完成 Python-only 浏览器 Agent 基础工程。
- 完成本地 Web UI、CLI、测试站与轨迹导出。
- 完成搜索、填表草稿、消息草稿、分析、查找、比较等核心功能。
- 完成 compare 多页采样、memory 聚合与推荐理由输出。

## v0.2.0 近期迭代

- 强化 compare 的候选过滤、字段归一化和价格/评分/日期对齐。
- 为 GitHub、文档站、课程网站增加更稳定的 domain skills。
- 优化 memory 检索，让多轮任务能持续复用上一步结果。
- 将真实浏览器 smoke test 固化成脚本化验收清单。

## v0.3.0 中期迭代

- 引入更稳定的多步骤 workflow 管理和任务状态恢复。
- 增加结构化导出能力，支持更标准的 JSON/CSV 对比结果。
- 提升真实页面元素重定位鲁棒性，减少动态页面误操作。
- 增加更完善的评测指标和回放报告。
