# 功能 Skill 拆分

## Skill 1：辅助搜索

### 输入

- 用户指令：`搜索/查找/帮我找 主题`
- 当前页面状态：搜索框、按钮、链接、正文文本。

### 行为

1. 如果当前页面存在搜索框，优先在页面内搜索。
2. 如果没有搜索框，则跳转到默认搜索引擎。
3. 如果页面已有结果，则提取与主题相关的标题、摘要或链接。

### 成功标准

- 搜索框被正确填写并提交，或页面中提取到相关内容。
- 结果日志中包含关键词、来源 URL 和提取片段。

## Skill 2：表单填写

### 输入

- 用户指令：`填写 姓名=张三 邮箱=a@b.com 主题=多模态`
- 当前页面状态：label、placeholder、aria-label、input name。

### 行为

1. 从指令中抽取字段键值对。
2. 将字段名与页面 input/textarea/select 匹配。
3. 填写字段，但默认不自动提交。
4. 高亮提交按钮并提示用户确认。

### 成功标准

- 至少 80% 的字段填入正确位置。
- 系统不自动提交高风险表单。

## Skill 3：消息回复

### 输入

- 用户指令：`回复小明：我今晚八点前发你`
- 当前页面状态：消息输入框、发送按钮、联系人文本。

### 行为

1. 识别回复内容。
2. 找到 textarea、contenteditable 或聊天输入框。
3. 填入回复草稿。
4. 高亮发送按钮，但不自动发送。

### 成功标准

- 回复内容出现在输入框中。
- 用户可以看到发送按钮的位置和系统解释。

## Skill 4：浏览器执行 Harness

### 输入

- Action list。

### 行为

1. 逐个执行动作。
2. 每一步返回 `ok/error`、目标元素、执行时间、页面 URL。
3. 保存轨迹，供评测和报告使用。

### 成功标准

- 同一动作 schema 可以同时服务插件 Demo 和批量评测脚本。

## Skill 5：页面总结

### 输入

- 用户指令：`总结当前页面`、`概括这个页面`、`提炼要点`
- 当前页面状态：标题、正文可见文本、标题层级、结果卡片。

### 行为

1. 抽取当前页面中的标题、段落、列表项和结果卡片。
2. 过滤导航栏、按钮等低信息密度文本。
3. 生成 3--6 条要点式摘要。
4. 将摘要展示在页面右下角，并写入执行日志。

### 成功标准

- 摘要覆盖页面核心模块。
- 输出可被复制到报告或后续消息草稿中。

## Skill 6：结构化抽取

### 输入

- 用户指令：`提取链接`、`收集邮箱`、`导出价格`、`抓取结果`
- 当前页面状态：链接、邮箱、价格、结果卡片、表格。

### 行为

1. 识别用户希望抽取的对象类型。
2. 从 DOM 中抽取结构化数据。
3. 输出 JSON 预览。
4. 支持复制到剪贴板。

### 成功标准

- 对链接、邮箱、价格、结果卡片至少支持一种结构化输出。
- 输出包含来源 URL 和抽取时间。

## Skill 7：结果比较

### 输入

- 用户指令：`比较搜索结果`、`对比这些商品`、`哪个更适合`
- 当前页面状态：搜索结果卡片、商品卡片、评分、价格、标签。

### 行为

1. 抽取页面中的卡片式结果。
2. 识别标题、摘要、价格、评分、标签等字段。
3. 按相关性、评分或价格给出简单比较。
4. 输出推荐理由。

### 成功标准

- 至少比较 2 个候选项。
- 给出简短、可解释的排序理由。

## Skill 8：界面分析

### 输入

- 用户指令：`分析这个界面能做什么`、`这个页面有哪些按钮`、`页面结构分析`
- 当前页面状态：可交互元素、按钮、输入框、链接、风险动作。

### 行为

1. 统计当前页面可交互元素数量和类型。
2. 推断页面支持的主要工作流，例如搜索、填表、回复、下载、筛选。
3. 标出提交、发送、删除、付款等需要谨慎确认的按钮。
4. 输出界面可用能力简报。

## Skill 9：项目分析

### 输入

- 用户指令：`分析这个项目的可复用性`、`这个项目能不能作为基座`、`架构分析`
- 当前页面状态：标题、模块卡片、README 标题、关键资源链接。

### 行为

1. 提取项目结构、模块或候选项。
2. 提取 GitHub、文档、License、Issue、Demo、论文等关键资源链接。
3. 给出可复用性判断和工程风险提示。

## Skill 10：页面查找

### 输入

- 用户指令：`帮忙查找 browser harness`、`页面中找 API key`
- 当前页面状态：可见文本、结果卡片、可交互元素。

### 行为

1. 查找相关文本片段。
2. 查找相关可操作元素并高亮第一个候选。
3. 输出结果并复制到剪贴板。
