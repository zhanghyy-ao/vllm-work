# Real-world Skills

本项目不能停留在本地玩具页面。真实可用版本需要面向常见网页任务，而不是固定页面结构。

## 场景 1：研究/搜索助手

### 用户指令

- `研究 浏览器智能体`
- `帮我找 HarnessAgent 相关资料`
- `总结搜索结果`

### 页面类型

- 搜索引擎结果页。
- GitHub 搜索页。
- 论文/博客/文档搜索页。

### 行为

1. 如果页面有搜索框，先输入主题并提交。
2. 如果页面已有结果卡片，抽取标题、链接、摘要。
3. 输出“来源列表 + 简短结论”。
4. 复制结果到剪贴板。

## 场景 2：GitHub 仓库理解

### 用户指令

- `分析这个 GitHub 仓库`
- `总结这个 repo 能不能用`
- `提取 README 重点`

### 页面类型

- `github.com/<owner>/<repo>`
- GitHub README 页面。

### 行为

1. 提取仓库名、README 标题、简介、安装/运行/License 线索。
2. 提取关键链接，例如 Issues、Pull requests、README 中的外链。
3. 给出“适合借鉴的点”和“工程风险”。

## 场景 3：文档站助手

### 用户指令

- `在文档中找 API Key 配置`
- `总结这一页怎么安装`
- `提取和 Playwright 截图相关的内容`

### 页面类型

- 技术文档、教程、README、博客。

### 行为

1. 基于标题、段落、代码块和链接抽取相关片段。
2. 输出 3--6 条摘要。
3. 保留来源 URL，方便报告引用。

## 场景 4：通用表单/消息草稿

### 用户指令

- `填写 姓名=张三 邮箱=a@b.com 消息=你好`
- `帮我给对方回复：我今天晚上发你`

### 页面类型

- 联系表单、问卷、评论框、聊天输入框。

### 行为

1. 匹配 label、placeholder、name、aria-label。
2. 自动填写草稿。
3. 高亮提交/发送按钮，但不自动发送。

## 安全边界

- 允许：搜索、打开链接、复制、填写草稿、提取公开页面内容。
- 默认拦截：发送、提交、删除、付款、下单、发布、上传文件。
- 高风险动作必须二次确认，且日志中记录拦截原因。
